Chapter 0

這是什麼？先選一種模式

PM&R Tool 把床邊評估變成一頁一題的問卷，做完直接產出可貼進病歷的文字。開始之前，先搞懂兩種使用模式的差別。

⚡ 訪客模式
  • 免登入，直接開始
  • 只存在這台裝置
  • 不綁病人、無病史
  • 產出：單次 note
  • 臨時評一個、借別人手機
🔑 登入模式
  • Access key ＋ 個人 PIN
  • 存伺服器，換手機看得到
  • 病人卡片、病史、對比
  • 產出：note、對比、週摘要、Email
  • 自己顧的病人、要追蹤變化
💡
評估頁面是同一套——題目、手勢、note 格式完全一樣。差別只在有沒有存到伺服器、綁到病人。

📋 入院完整評估

Chapter 7

常見問題

幾個實際會踩到的狀況。

資料相關

問題答案
訪客紀錄留多久？直到你清除瀏覽器資料。首頁只列今天的，舊的還在。無痕視窗關掉就沒了。
換手機看得到嗎？登入模式可以，訪客模式不行。
病人會被自動刪除嗎？7 天提示 → 14 天紅標籤 → 28 天清除。出院請直接 Remove。
沒網路能用嗎？訪客模式的評估可以填；登入、病人清單、存檔、寄信都要網路。
ASIA 評到一半重新整理？不會清空（有本機草稿）。但從首頁 ASIA 入口重進會開全新的。

操作相關

問題答案
ASIA 點錯了？沒有復原鍵，繼續點回去（分數循環）。
捲動會改到分數嗎？不會。移動超過 10px 就判定為捲動。
某項目沒測怎麼填？留空。空白＝沒評，不會進 note。ASIA 用長按設 NT。
「全部正常」能取消嗎？按完會鎖成綠色，但個別項目仍可點開改值。
做到一半要離開？綁病人時按右上「暫存」；訪客模式會自動留在本機。
突然跳回 access key 頁？登入逾時，重新輸入即可，已存資料不受影響。
🔐
只收病歷號與床號，沒有姓名欄位。不要把姓名或身分證號打進病歷號欄——它會出現在所有畫面、note 與 email 裡。
🎉
教學結束。建議先用訪客模式空跑一次熟悉手勢，再拿去床邊用。
